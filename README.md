# 🎧 PDF to Audiobook Converter

A simple Python project that reads PDF files aloud. This script extracts text from a PDF document page by page and uses a text-to-speech engine to play it back as an audiobook.

## Features
* Extracts text from any PDF file.
* Reads the content aloud sequentially.
* Customizable starting page (defaults to the beginning of the book).

## Technologies Used
* **Python 3**
* **PyPDF2**: For reading and extracting text from PDF files.
* **pyttsx3**: A cross-platform text-to-speech library.
